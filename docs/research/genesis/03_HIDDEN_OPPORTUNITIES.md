# Скрытые возможности и оригинальные комбинации

Дата/источники — [реестр](data/evidence_registry.csv). Оригинальность ниже — синтез исследователя, не заявление о патентной новизне, отсутствии конкурентов или спросе. Все предлагаемые цены/экономия/каналы ASSUMED до пилота.

**Методы поиска.** Negative review mining: ограниченная выборка low-star Matrixify [E02/E03], два отдельных billing/expectation complaints; ответы поставщика сохранены в выводе, общая частота жалоб UNKNOWN. Повторяемость потребности в независимом QA пока не доказана. Expensive workflow decomposition: этапы C01/C02/C03 в [01](01_MONEY_FLOW_MAP.md); обязанности по доступу, interpret и acceptance остаются ручными. Ecosystem gap: сравнение с dry-run/history/free tools до идеи клона. Forced migration radar: официальные даты с проверкой, что trigger не просрочен [E29–32]. Competitor arbitrage: дешёвые incumbents скорее опровергают «сделаем дешевле», чем подтверждают нишу. Distribution first: Matrixify referral наблюдается, но открыт только trusted experts; Project Catalog допускает review, не обещает спрос [E09/E45/E49].

Пять собственных механизмов O01/O03/O04/O05/O08 комбинируют данные, автоматизацию, объяснение AI, интеграции и существующую платную работу. Используются только разрешённые public schemas/docs и данные клиента с согласием; ничего не предполагает право собирать чужие магазины/письма. Ни один механизм не получил moat только за AI. Возможная защита — накопленные разрешённые fixtures, measured delivery, доверие и повторные agency contracts; всё это пока отсутствует.

Не делать original invention ради названия: O07 без основной оплаченной миграции не продукт; O09 без workflow inventory — обычный newsletter; O11 без host agreement — воображаемая дистрибуция.
