# Broad discovery → фильтрация

45 гипотез, по три в каждом из 15 механизмов. Полный построчный набор: [opportunity_universe.csv](data/opportunity_universe.csv). Это ориентир 40–60 выполнен без притворства, что везде найдены расходы. Строки без evidence IDs — оригинальные discovery hypotheses, все коммерческие утверждения UNKNOWN/ASSUMED. Нельзя ссылаться на их число как на доказательство рынка.

Stage A: широкий набор и бесплатные substitutes. Stage B: 15 именованных кандидатов в scorecard. Stage C: углублены C01–C06; для них минимум три функциональные alternatives. Stage D: 15 отдельных adversarial reviews. Stage E: один экспериментальный финалист, ноль build-ready. Количество 10 — максимум, а не обязательная квота.

| Механизм | Что искали | Итог |
|---|---|---|
| Ecosystem-native | feed/export/Workspace gaps | Existing apps + marketplace cold start; не строить generic app |
| Paid workflow replacement | migration QA/restore/invoice exception | C01 лучше всего привязан к buyer budget |
| Mandatory spending | KSeF/Gmail/accessibility | Free/native + applicability + expertise gates |
| Integration bottlenecks | QBO/webhooks/consent | Paid tools есть, наша дифференциация UNKNOWN |
| Software migration | SharePoint/Drupal/OneSaas | Triggers реальные, часть уже прошла; successors бесплатны |
| Vertical micro-SaaS | clinic/trades/training | Buyer spend и acquisition не подтверждены; REJECT как near-term build |
| Productized B2B | acceptance/inventory/smoke | Быстрее test без production, но всё ещё labor business |
| Agency white-label | restore/runbook/release proof | Recurring leverage возможен, доступ к agency UNKNOWN |
| Data products | renewal/catalog/API impact | Наличие данных не buyer intent |
| Marketplace gaps | CSV edge-cases/admin/legacy export | Нужен конкретный открытый paid request, не scraping volume |
| Developer tools | reliability/tests/cost guard | Mature free alternatives; clone REJECT |
| Compliance/reporting | KSeF/accessibility/deletion | Границы legal sign-off и PII; не обещать compliance |
| Outcome-based | disputes/recovery/overcharge | Advertised fee real; attribution/settlement barriers |
| Embedded | bookkeeper/MSP/host | Доступ к партнёру не доказан каталогом |
| Unconventional | provenance/fixtures/handover | Тестировать willingness to pay, не объявлять уникальными |

Гипотезы с недоопределённым buyer имеют REJECT hard gate в scorecard; broad ideas со статусом UNVALIDATED не допускаются к build. Никакая слабая строка не проходит по суммарному баллу.
