Доказанные банковским документом collected revenue во всех строках: UNKNOWN. У E02 есть только самоотчёт об оплате и ответ поставщика. Выручка клиента, накопленные platform spend и hire не превращаются в выручку конкретной услуги.

Разложение expensive workflow C01: intake scope (human 1h) → deterministic key mapping/counts/totals (code, 3h) → interpret unmatched/rounding/currency (human 2h) → sample URLs/media (bounded consented checks later, 1h) → acceptance discussion и revisions (human 2h) → support reserve (1h). Итого 10h ASSUMED, не «90% AI». Только первые два этапа частично доказаны offline; tax equivalence/SEO outcomes/paid checkout не входят. C02: получить разрешённый backup → isolated restore → secrets/email/payment disable → smoke → report → delete; ручные permission/security steps нельзя считать бесплатными. C03: inventory → owner approves known senders → read reports → propose DNS diff → owner review → staged change/rollback; автономный reject policy запрещён нашим scope.
