# Как получить первых 100 пользователей или пять B2B-покупателей

**Доказанного воспроизводимого пути с нужным объёмом не найдено.** Ниже конкретные механизмы и точки, где они обрываются. Поэтому ни один продукт не рекомендован к полноценной разработке. Существование карточки, контакта или программы не равно доступу к её аудитории.

| Кандидат | Конкретный механизм | Что наблюдалось | Чего не хватает для 100 users / 5 buyers |
|---|---|---|---|
| F01 Export Acceptance Kit | Один partnership intake Maukau → scoped migration pilot → повторное использование агентством | Категория партнёрств P18; смежный buyer budget в прежнем исследовании S32 | Принятие подрядчика, коммерческий scope, цена, пять сделок, repeat и банк |
| F02 Woo definitions diagnostic | Разрешённый supplier/agency intake → согласованный обезличенный пример → платный diagnostic | Вопрос G10 и vendor support; отдельный supplier intake не найден | Платное действие вместо бесплатной консультации; нельзя рекламироваться автору темы |
| F07 Shift break audit | Релевантный store query → listing view → install → activation | Существующие Supershift/MyShiftPlanner и жалоба R01 | Search volume, rank новичка, первые показы и opt-in testers; всё UNKNOWN |
| F09 Inspection pack | Отраслевой интегратор → один шаблон → его клиенты | Paid ecosystem и crash reports R15 | Ни один интегратор не подтвердил buyer access; template adoption UNKNOWN |
| F13 Redirect evidence | CWS после review → точный workflow query → activation | Checkbot уже продаёт этот workflow X12 | Причина выбрать нас и объём установок UNKNOWN |
| F14 Table schema checker | Разрешённая выбранная таблица → sample checker → agency license | Платный Table Capture и free substitutes | Наш отдельный результат, точный профессиональный сегмент и канал UNKNOWN |
| G01 future plugin | Бесплатное полезное ядро в WP directory → использованный report → premium license | Механизм каталога S14 существует | Допуск, показы, активация, конверсия и стоимость free support UNKNOWN |

В B2B по пять продаж при 20% close нужно 25 **квалифицированных** возможностей. Два подходящих intake не дают 25 opportunities: каждый может не ответить, отказаться или потребовать готовый продукт. Для $79 license нужно 26 активных агентств; initial acquisition при том же условном close — 130 opportunities. Ни один каталог этого не доказал. Не подменять имена организаций квалифицированными buyers.

Для первых 100 consumer installs при условной listing-view→install конверсии 20% нужно 500 подходящих просмотров карточки; при 5% — 2 000. Для 100 activated users при 50% activation это ещё вдвое больше installs/views. Эти значения — пороги, не ASO benchmarks. Нельзя считать installed competitor users нашей будущей воронкой.

Органическая выдача проверена поисковыми запросами, перечисленными в [методе](research_method.md): видны зрелые продукты и документация, а не измеренная свободная ниша. Live app-store/CWS rank census, keyword volume, CPC и CPI не получены. Не использовали персонализированную выдачу как объективную частоту. «SEO», «ASO» и «опубликовать на Reddit» не засчитаны каналами: промо-правила конкретных communities не проверены, гарантированные показы отсутствуют.

Платное привлечение: реальных auction quotes и своей конверсии нет → CAC/CPI UNKNOWN. [Модель](06_SUBSCRIPTION_ECONOMICS.md) показывает лишь break-even thresholds и расходы $0/$100/$500/$1 000 без обещания приобретённых пользователей. При низком годовом чеке $49 стоимость бесплатной поддержки может съесть рекламный бюджет ещё до первой оплаты.

Встроенное распространение: SendPulse S28 прямо предлагает integration link/анонс/возможный reward, но только после согласования конкретной интеграции. Уже существующая Woo-интеграция S29 исключает простую копию. Vendor entry Vendasta P15 реален, но активация реселлеров и коммерческие terms неизвестны. Family sharing внутри приложения расширяет использование одной семьи, не доказывает внешнее распространение или второго плательщика.

Если 14 дней разрешённого теста не дадут достаточного exposure, вердикт INSUFFICIENT EXPOSURE, а не «рынка нет». Следующее действие — изменить один канал/сегмент, не добавлять функции. Ни unsolicited outreach, ни сообщения в support threads, ни scraping каталога не разрешены этим исследованием.
