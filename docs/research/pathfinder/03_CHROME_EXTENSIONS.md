# Пятнадцать идей расширений Chrome

[Карточки X01–15](data/extension_ideas.csv) содержат workflow, частоту, платную ценность, конкурентов, аудиторию/отзывы, бесплатную замену, разрешения, MV3, оплату, поддержку и каналы установок. Источники — [реестр](data/evidence_registry.csv).

| ID | Узкий workflow | Почему не очевидная покупка |
|---|---|---|
| X01 | Проверка получателей перед разрешённой рассылкой | GMass и native Gmail; доступ к почте чувствителен |
| X02 | Переносимые командные snippets | Magical, Text Blaze и функции ОС; подтверждённого forced migration нет |
| X03 | Редактированные скриншоты для приёмки | GoFullPage $12 в год плюс бесплатный редактор |
| X04 | Изменившиеся шаги инструкции | Scribe/Tango; надёжное скрытие данных сложно |
| X05 | Наблюдение разрешённых изменений документа | Distill free; условия сайтов и сон service worker |
| X06 | Передача групп вкладок клиенту | Toby, bookmarks, native tab groups |
| X07 | Проверяемый бэкап сессии | OneTab/Session Buddy и другие бесплатные решения |
| X08 | Проверка структуры выбранных заметок | Обычный шаблон и AI часто достаточны |
| X09 | Передача списка технологий сайта | Wappalyzer basic бесплатен; сбор контактов исключён |
| X10 | Отчёт об a11y-регрессиях компонента | axe/Lighthouse бесплатны; это не certification |
| X11 | Проверка схемы разрешённой таблицы | Table Capture, clipboard, Sheets; отдельный спрос неизвестен |
| X12 | Приёмка redirect manifests | Checkbot уже продаёт CSV/PDF и проверки |
| X13 | Повтор одного QA fixture | Requestly/DevTools; высокие host/network permissions |
| X14 | Согласование изменений автоматизации | HARPA/native scripts; правила сервиса и remote code |
| X15 | Checklist передачи секретов | Bitwarden/free checklist; сами пароли не собирать |

Аудитория: Magical 200K displayed users [R12]; Requestly 300K/1.8K ratings/4.7 [R14]. У Toby 300K/3.3K и Distill 400K/1.5K, но рейтинги в snapshots расходятся [R10/R11]. Не выбираем удобную цифру. Table Capture 605/4.15 — вторичная сводка [R13]. Checkbot сообщает 80K пользователей и 1 000+ upgrades [X12]: это полезный vendor signal, но не независимо проверенные invoices и не наша аудитория. Для остальных точные counts оставлены UNKNOWN.

Toby $4.50/$8 — эквивалент годовой оплаты; месячные планы $6/$10. GoFullPage «$1 в месяц» означает $12 годовой платёж. Цена Requestly API Platform не приравнена к цене browser interceptor. Жалоба на export paywall не доказывает готовность купить наш schema checker.

MV3 [S09]: service worker может быть остановлен; состояние сохраняется в storage, а не в памяти процесса. Нельзя обещать непрерывный локальный daemon. Исполняемая логика должна соответствовать packaged-code/remote-code rules; использование webRequest/DNR требует проверки конкретного API. Ответ AI нельзя превращать в удалённо доставляемую исполняемую логику в обход review.

CWS [S10] требует одной понятной цели, минимальных разрешений и правдивой обработки данных. Разрешение браузера не даёт права скрапить CRM/Gmail или обходить правила сайта. Предпочтительны выбранный пользователем файл, activeTab и optional permissions. Никаких скрытых чтений паролей, истории, affiliate redirects или рекламы в чужом интерфейсе. Для обычной сверки CSV расширение вообще не нужно: локальная web page может дать тот же результат.

Встроенные платежи CWS прекращены [S11]. Нужны внешний checkout, лицензия, privacy/support pages и обработка entitlement/refund. Фактический PSP/MoR для Украины и этого продукта UNKNOWN; native Stripe не предполагается [S23]. Одноразовый registration fee существует [S12], но его точная текущая сумма в полученной первичной странице не подтверждена — она оставлена UNKNOWN.

Реклама [S13] входит в проверку продукта. Скрытая подмена ссылок и маскировка рекламы в стороннем сайте не являются бизнес-моделью. Даже допустимая реклама в собственной UI требует disclosure, privacy и достаточных показов. Профессиональный инструмент с редкими экранами скорее подходит лицензии, но её конверсия также неизвестна. Проверенного пути к первым 100 установкам нет; все расширения остаются вне build-ready списка.
